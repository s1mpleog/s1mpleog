## `> about`

I like understanding things from the bottom up.

Currently interested in:

* low-level systems
* C / C++ / Rust
* x86-64
* operating systems
* graphics & Vulkan
* compilers and code generation
* memory, ABI & calling conventions

I prefer making things close to the metal over hiding them behind abstractions.
